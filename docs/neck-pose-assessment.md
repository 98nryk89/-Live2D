# 提供された首かしげ3枚の確認

アーカイブ3の3枚を原本のまま保存し、PNGの大きさと透明度、胴体の位置合わせ、髪の対応点による頭の見かけの回転を調査。今回の作業は素材確認で、配布アプリは0.9.0のまま。

## 使える点

- 全3枚が1350×1165px、RGBAのPNG。原本はneck_pose_originalsにSHA256付きで保存。
- 顎と首のつながり、首の左右輪郭、顎下の影、襟との関係の参考になる。首の形の正解候補として残す。
- 胴体の特徴点は1407〜1600点が位置合わせに採用され、対応点の誤差中央値は0.45〜0.66px。胴体の倍率差は約0.1〜0.2%と小さく、比較用に位置合わせできる。
- 衣装の色や細部の画素は同一ではないため、既存モデルの胴・熊・衣装・顔をこの全身画像へ置き換えない。首周りの情報に用途を限定する。

## 角度の注意

| アップロード画像 | 役割 | 既存の真っ直ぐな基準との差 |
| --- | --- | --- |
| 右傾きの貴族風くま耳少年.png（投稿1枚目） | 画面右へのかしげ | 時計回り約10.7度 |
| 左に傾く熊耳少年の華麗な制服姿.png（投稿2枚目） | 画面左へのかしげ | 反時計回り約12.2度 |
| 無価値価値の自然な首元修正版.png（投稿3枚目） | 正面用に生成した画像 | 反時計回り約6.7度 |

これは胴体を位置合わせし、髪の対応点から求めた画像上の回転の概算。首の解剖学的角度の実測値ではない。既存モデルの正面補正6.530486度を含む基準との比較。
髪の対応点採用数は30/49/103点、誤差中央値0.84/0.67/0.49px。生成した3枚をそのまま0/±5度のキーにしてはならない。原画基準からの回転は約+17.27/-5.66/-0.12度で、正面用の頭は元の傾いた頭の姿勢に近い。
角度は実装時に位置合わせと対応づけを行う。生成のやり直しを先に要求せず、形の資料として保持。アプリの左右5度の可動域は維持する。

## 足りない情報と次の素材

3枚はそれぞれ完成した全身1枚絵で、首の肌と顎下の影が一体。顎の裏や襟の下の首は見えていない。投稿3枚目は首筋の陰影も強い。これらを肌ごと伸ばして使うだけでは、以前の固定影・補完肌の問題が残る。
追加素材の優先は、投稿3枚目を添付して生成する「顎下の投影影を含まない首の肌だけ」の透過PNG1枚。1350×1165のキャンバスと首の位置・大きさを維持し、顎裏と襟裏の重なり20〜30pxを描き足す。首全体を画面中央へ拡大して配置しない。上端と下端に黒い切断線を描かない。
顎下の影や襟の別素材がさらに必要かは、肌単体を受け取ってから、既存の差分・元絵から分離できる範囲を確認する。一度に全パーツの追加生成を求めない。

## ChatGPTへの次のプロンプト

投稿3枚目（無価値価値の自然な首元修正版.png）を添付し、以下を貼り付ける。

```text
添付画像から、Live2D用の「首の肌だけ」の素材を1枚作ってください。

添付の首の位置・大きさ・肌色・絵柄を基準にしてください。
出力に描くのは首の肌だけです。頭、顔、顎、髪、耳、服、襟、熊、アクセサリーは描かず、それ以外の部分はすべて透明にしてください。

首の上側は顎に隠れる部分まで、下側は襟に隠れる部分まで、それぞれ20〜30px程度、同じ肌として描き足してください。
首の上端と下端には黒い輪郭線を付けないでください。
左右の輪郭は自然な首の形を保ってください。

顎から首に落ちる影は入れないでください。首筋の濃い影や筋の描写を強調せず、元の絵柄に合う淡い肌のグラデーションにしてください。

背景透過PNG、1350×1165px。
首は添付画像と同じ位置に残してください。首だけを拡大した画像にしたり、キャンバスの中央へ移動したり、トリミングしたりしないでください。
出力は首の肌だけの素材1枚です。
```

生成した元PNGをZIPで受け取る。その位置・色・形と描き足しを確認したうえで、首の輪郭と太さを見本へ合わせ、影と襟の前後を分けて変形を設計する。素材受領だけで自然さの解決を保証するものではない。
