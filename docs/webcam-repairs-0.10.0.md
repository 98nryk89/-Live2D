# Webカメラ版0.10.0：提供された首肌レイヤーを組み込んだ構成

受領した透過PNGと、アーカイブ3の首かしげ資料を使い、首の構成を更新した検証版。追加の画像生成は行っていない。自然さは比較画像と利用者の実際の見え方で確認し、数値検査だけで解決済みと判断しない。

## 素材

原本：character_materials/mukachi_kachi/neck_skin_originals/透明背景の淡いアニメ調ネックレイヤー.png。1350×1165、RGBA、SHA256はprojects/mukachi_kachi/neck_materials.jsonへ保存。
実際の首の不透明領域はおよそx585〜779、y402〜568。背景の極低アルファの点が広く残っているため、首の連結領域と1pxの余白だけを描画用に採用。原本は変更しない。
顎裏の重なりを確保するため上へ20px移動する。肌色は正面用に受領した首の色に合わせ、微小なチャンネル補正を加える。変換量と参照元をneck_materials.jsonへ記録。顔・髪・衣装を再生成しない。

## 旧構成からの変更

- 頭は元絵の実際の顎線までで分離し、全体を共通の頭変換で動かす。旧y438〜490の帯による首の引き伸ばしを頭から除く。
- 首は提供された肌を使う独立したneck_skin。上端は顎側の左右の取付点、下端は固定した襟元を基準にした曲面で動かす。曲がる中心線と幅・断面角を分け、上下左右の複合姿勢でも裏返らないようにする。3D解剖モデルではなく2Dの曲面近似。
- 古い首の肌を胴側から除き、固定されていた肌の補完板neck_backingを廃止する。
- 顎下の影jaw_shadowは、正面用の首差分から得た色を使う局所レイヤーとして分離し、顎に追従させる。描画時は首の肌の内側へクリップする。影の3D照明計算ではない。
- 襟の奥と手前を分け、肌を衣服の後ろへ重ねる。首の下側の描き足しが衣装へはみ出さないよう、胴と手前の襟で隠す。
- 真っ直ぐな頭の基準、左右5度、表情と口、熊の笑顔・4秒周期の瞬き、装飾9点の重力と0.5の揺れ量は維持。

首肌の配置と幅は、3姿勢の資料と元絵の顎・襟の位置を見比べて調整した。生成差分の見かけ角度は指示の0/±5と異なるため、全身画像や首の画像をそのまま切り替える方法にはしていない。

## 検証

tests/verify_neck10.py：承認済み122パーツの画像・メッシュ・効果、物理と入力設定の前版一致。頭の旧首重みと固定肌板の廃止。原本SHA、上端取付点と固定下端、首と頭の反転なし、首内側の透明穴なし、顎影の肌へのクリップ、顔の描画が前版とほぼ一致すること、JSエラーなし。
左右±5度に加え±2.5度と、上下左右を組み合わせた最大姿勢を検査。最初の試作で首幅不足による側面の隙間を検出して配置幅を修正し、複合姿勢で下端の隠れた広い部分に反転があったため断面角の補間を修正した。最終出力で再検査。
tests/verify_webcam_distribution.py：配布HTML、疑似カメラ起動停止、許可エラー案内。顔検出器は模擬。
neck_before_after.jpg、neck_review.jpg、neck_motion.gifで静止・中間・連続動作を目視。実Macカメラ/OBSは未確認。
