# Webカメラ版0.8.0：重力で垂れる装飾

依頼：動きに反応するだけでなく、止まると下に垂れる物理へ変更。首の違和感について現在把握している課題を説明する。今回、首の修正は行わない。

## 装飾の変更

旧版は入力の速度・加速度でばねを揺らし、値0＝元の描かれた角度に戻していた。重力の方向を持たず、頭と一緒にイヤリングの静止角も回っていた。
新版はviewer/pendulum.jsの2D減衰振り子。取付点とアルファ面積による重心近似から長さを決め、頭の投影・回転・全身移動を反映した取付点の画面内位置を追跡する。移動加速度が慣性の外力となる。重力はモデル座標+Y、2200px/s²、減衰比0.24。取付点の加速度は45msのフィルタを通す。最大65度の可動範囲で数値積分する。
角度thetaは画面下向きを0とする。振り子の接線方向の加速度は `(ax*cos(theta) - (g-ay)*sin(theta))/L - damping*omega`。長さL、g、時刻はモデル内の2D単位。実寸の重さを測定したものではなく、鎖同士や服との衝突を含む3D剛体計算ではない。
描画は頭などの変形の後、取付点を固定して重心が重力方向へ回るよう補正する。このため頭を±5度傾けたまま停止しても、イヤリングは元絵の傾きへ戻らず下へ垂れる。AccessoryGainは動きへの反応を調節し、0でも重力の向きは保持する。

独立回転すると、札型イヤリングの金の外縁が頭/胴に残っていることが確認できた。色による境界推定が金縁を除外していたため、このイヤリングだけ全外周を含む輪郭へ変更。以前の金縁を下地から取り除く。ほか8点の切り抜きは変更しない。

## 首について分かっている問題と限界

首の画像領域（x610〜765、y385〜505）と変形効果は0.7.0と完全一致。今回の頭/胴画像の変更は札型イヤリング外縁（x774〜820、y357〜470）に限定される。
現在は、首の左右の線や解剖学的な接続点を動かす仕組みではなく、y438〜490の高さとx616〜755の帯で頭の変形量を落としている。その外側は重み1へ戻る。連続メッシュにしても、首の太さ、皮膚の伸び、顎との接続を個別に制御できない。
さらに、顎下の影は元絵に描き込まれたまま変形し、隠れた肌には近い肌画素のコピーを使う。首の体積・光の向きに合わせて陰影を再構成していない。固定の補完肌・前面の襟との境界も残っている。正面補正6.53度を加えた状態と固定襟を、この重み補間でつないでいる。
これらは実装から確認できる制約。利用者が感じているどの境界・陰影が最も強い原因なのかは、手元の描画だけで断定しない。穴やメッシュ反転がない検査は、自然な首であることの証明ではなかった。課題は未解決。
次に必要な設計は、顎下の接続、首の左右輪郭と太さ、固定襟との前後関係、顎下の影を分けて制御すること。現状はその段階まで実装できていない。
