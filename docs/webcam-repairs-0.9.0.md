# Webカメラ版0.9.0：揺れ幅を抑え、首の素材依頼を具体化

依頼：重力を含む現在の揺れ方を維持し、幅を抑える。首の解決方針、必要素材と利用者がすることを提示。

## 揺れ

AccessoryGainの初期値を1.0→0.5に変更。重力・減衰・長さ・支点・振り子の式・可動範囲は変更しない。移動加速度による反応が半分になり、下へ落ち着く動作は維持する。大きな入力時は非線形計算と角度上限があるため、全状況で角度が厳密に半分になる指定ではない。
同じ模擬入力で全9点の角度振幅が旧版の50.1〜50.4%となること、頭を5度傾けた停止状態でも下へ落ち着くことを検証。UIの揺れ量から追加調整できる。
今回の入力設定だけの変更で画像生成はやり直さず、out/rig.jsonの初期値とbuild_character.pyの再生成時の初期値を一致させた。全128パーツの画像・メッシュ・効果と、物理定義が0.8.0と完全一致。首は未変更・未解決。

## 首の解決方針と素材

docs/neck-material-request.mdを作画依頼書として保存。
正面のレイヤー付きPSD（頭は顎まで・首の肌・顎下の影・襟の前後）と、0度・画面左5度・画面右5度の完成見本PNG3枚を推奨。PSDが難しければレイヤー別透過PNGでよい。左右の差分は首の輪郭・太さ・影の正解見本として使い、全身画像の回転や画像切替で動かす方式にはしない。
首の肌は顎や襟に隠れる領域を描き足し、影を独立させる。胴・襟・熊は固定し、顔は正面のままかしげる。既存の顔・衣装を流用し、首周りの加筆とレイヤー分けを依頼する。
資料を受け取ったら、首の左右輪郭と太さを3姿勢の正解へ合わせ、顎下の影を首の肌に収め、襟の前後で重なりを管理する。両端と正面に加え途中の±2.5度も比較して調整する。素材だけで自然さを保証せず、変形設計と動作の確認も必要。
