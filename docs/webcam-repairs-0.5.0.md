# Webカメラ版0.5.0

依頼：右だけ10度、指定の笑顔の目を復元、熊耳と髪を切り直して色分けで提示、装飾を揺らす。

## 変更と確認できた原因

- かしげ：入力・リグとも左5度／右10度。頭・目・口・頭上の耳は共通の頭変換、首のみ重み付き。肩の熊は胴に固定。
- 笑顔：前版の3段階瞬き対応時に笑顔レイヤーを外し、閉じ目で代用していた。最初の提供笑顔の左右目を復元。笑顔中は通常の瞬きより笑顔の目を優先する。通常の開・半開・閉6枚と口98レイヤーは承認済み版と完全一致。
- 熊／髪：従来の横方向境界と概略ポリゴンでは、熊の輪郭と髪が混ざり、胴にも動かない髪が残っていた。原本の輪郭に沿う領域をGrabCutで精緻化し、肩の熊、頭上の左右の耳、髪を独立。熊・耳を頭と胴の両方から除去し、境界の細い除外余白を設けた。隠れていた髪は提供の装飾なし画像だけから補う。頭上の耳は別レイヤーでも頭に固定する。生成AIで見える元絵を描き直していない。
- イヤリング2点・タッセル7点：房の輪郭を切り直し、金具・房の実画素位置へ揺れの支点を合わせた。赤い宝石は暗い下半分が色による切り抜きから脱落したため、金縁と先端まで手動輪郭で含めた。隠れる裏面は提供画像を使用。ばねの揺れと慣性を増やし、静止時も微動する。全鎖・全宝石を分割したものではない。
