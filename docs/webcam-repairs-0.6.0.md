# Webカメラ版0.6.0

依頼：真っ直ぐな頭を初期状態にし、そこから左右5度。装飾は動きに合わせて揺れる。かしげ時の首・襟を修正。良好な切り抜きは保持。

## 修正

- 原画の目の高さに約6.53度の傾きがあり、パラメータ0でも斜めに見えていた。提供された通常開眼の左右の虹彩の色から中心を測定し、原画の姿勢を時計回りに6.530486度補正する。顎付近(687,435)を基準に頭・髪・耳・表情・耳飾りへ同じ補正を適用。入力のAngleZは0のままで正面となり、そこから左右5度ずつ回る。較正・リセットでもこの基準を維持する。
- かしげの入力とリグをともに±5度へ統一。全体移動、顔の上下左右と分離する。
- 装飾の常時正弦波による自動揺れを0にし、頭の角度と全体移動の速度・加速度でばねを駆動する。減衰を持ち、止まったら落ち着く。イヤリング2点、タッセル7点。リセット時の古い入力履歴も消す。独立した装飾の変位は、同一の頭・体姿勢で物理ON/OFFを比較して確認した。
- 首は従来y435で分断され、元の襟の黒い線も首と一緒に動いていた。顎下の原画を重ねて頭との接続を保ち、首の重みを滑らかに下げて襟元で固定する。首のメッシュは4px間隔。首の動く領域から襟の黒線を外し、前の襟を原画のまま独立レイヤーで胴に固定・前面に描く。
- 動いた首の下の隠れた肌だけ、元の首の肌画素から最近傍で補う。黒い顎線や襟線は補完元にしない。表示中の目・口を再生成しない。
- 熊・頭上の耳・髪の裏面・装飾・目・口の123レイヤーについて、0.5.0のPNGとメッシュが完全一致。頭と首の変更は襟付近のみ。承認済みの熊と髪の分割を維持。

承認された熊・髪と装飾の切り抜きは維持。旧0.5.0 ZIPを保持。新しい追加素材は今回不要。実Macのカメラ・OBSの動作と見え方は未確認。
