# Webカメラ版0.7.0

依頼：かしげた首の分断を自然につなぐ。装飾の揺れを強める。笑顔で熊の片目が崩れる点を修正し、熊を約4秒ごとに瞬きさせる。

## 首

前版は頭の画像の下端y435と別の首レイヤーを重ねており、透明穴がなくても変形と陰影の境界が見えていた。固定の胴にも首の側面画素が残っていた。
今回は頭と喉を単一のRGBAテクスチャ・4px間隔の連続メッシュに統合し、首の別レイヤーを廃止。顎までは頭に追従し、y438〜490で滑らかに変形量を落として襟元を固定する。髪の先を首と同じ重みで縮めないよう、首の左右範囲を限定する。胴に残る古い首を除き、固定の襟の原画・黒縁は前面に保持。必要な隠れ肌は元の喉の肌画素だけから補う。
真っ直ぐな基準姿勢と左右5度を維持。熊・髪の裏・頭上の耳・人の表情・装飾など122レイヤーのPNGとメッシュは0.6.0と完全一致。首を含む頭のメッシュのみ今回の方式へ変更。

## 装飾

動きに反応する物理を維持して、外力ゲイン18→28、減衰0.65→0.60へ。最大回転はイヤリング8→10度、タッセル6→7度。一定周期の自発的な揺れは追加していない。
同じ模擬入力を前版と新版へ入れた比較で、イヤリングの角度振幅が1.45〜1.52倍、タッセルが1.89〜1.90倍。停止後の減衰を確認。AccessoryGainの調節は従来通り。

## 熊

従来の全眼領域を一つの楕円で切り出す処理では、斜めに並ぶ右目が楕円の端にかかり、閉じ目が欠けていた。左右それぞれの提供された笑顔の目を、完全不透明な芯と細い境界で配置する。右目は鼻・口へかからない斜めのマスクも設定。旧companion_smileを削除し、目以外を置き換えない。
通常時はCompanionEyeOpenで両目を同時に閉じる。人のカメラ・自動瞬きとは独立した4秒周期、約0.18秒の閉開。笑顔中は閉じ目を維持。熊の瞬きチェックボックスで独立してON/OFFでき、初期ON。
提供された閉じ目の形と色を使い、眼球を縮めて中間形状を作らない。中間の閉眼差分は提供されていないため、素早い開閉として表示する。
