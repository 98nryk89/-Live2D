# 無価値価値 Webカメラ版0.3.0

利用者指定：閉じ目の周囲のぼけ・瞼消失、通常口と他の口形の傾き、左の角度を戻すこと、右かしげで顔の左が残る引き伸ばしを修正。

## V完成版から確認した構造
98nryk89/VのMOTION-5完成版（91f240f75a437830697126397fce60a8202b6b16）を読み取り専用で確認。projects/owl_prince/rig_spec.jsonではface/目/口が共通のhead変形、neckだけにy方向の重み、bodyは別変形。docs/face-mouth.md、docs/brows-rotation.mdでは顔と首の分離、顎の裏の局所肌補完、3D行列による回転を記録している。

このキャラの0.2.0では肩の小熊を除外する楕円の重みが顔左側に及び、顔内の回転量が異なっていた。Vのキャラ座標・画像は使わず、このキャラの画素を頭・首・胴に分割して同じ考え方へ変更した。

## 変更
- 左かしげは元の5度へ戻す。右は12度を保持。入力とリグの両方を-5〜+12度へ変更。
- headに小熊除外の重みをかけない。顔・目・口・眉・頭髪・耳は同じ頭部変形で回転する。neckだけy435〜490で頭→胴につなぎ、首の裏の隠れた部分は元絵の首の肌から局所的に補完。肩の小熊・胴・房は体側に保持。
- 閉じ目の肌を広くinpaintする処理を廃止。提供された閉じ目画像の瞼・二重線・ハイライト・陰影を、開口に合わせて局所リマップする。眉・周囲の髪・頬の星を保持し、虹彩を縦に潰さない40段階は維持。
- 通常口の傾きを画像座標で約-7.4度と測定。横長の口は口端から軸を測り、丸い「あ」は正立、縦長の驚き口は楕円軸を基準として、唇・口内だけを通常口の軸へ合わせる。その局所軸に沿って32段階で開閉する。周囲の肌・顔輪郭は回さない。通常口自体は変更しない。
- 0.2.0のZIPは保持。新しい0.3.0のZIP/フォルダ/HTML名を用意した。
