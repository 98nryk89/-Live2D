# Webカメラ版0.12.0：熊側の顔を8度へ

画面左（熊側）の顔のみ5度から8度に拡張。首は左右5度、右側の顔は5度を維持する。追跡入力と操作スライダーのAngleZ範囲は-8〜+5。

従来の頭/首回転を±5で止め、-5を超えた分を変換後の顎中心へ追加する。顎中心がさらに移動して首を引っ張ることを避ける。首の線形重み、支点467.08、原画の首輪郭と陰影、固定襟、全パーツPNGとメッシュは0.11.0と同一。顔パーツ・頭上の耳・耳飾りは追加回転に追従し、肩の熊は胴に固定。耳飾りの物理支点にも同じ変換を適用。揺れ量・重力・熊の瞬き・表情を維持する。追加の生成素材は不要。

`tests/verify_face_left12.py`は前版と正面/左右5度の実描画一致、左8度で首が左5度と完全一致、顔だけ追加3度、顎中心固定、複合姿勢でメッシュ反転なし、首内部の不透明度、装飾取付点と重力復帰を確認する。比較画像はverification/repair_0.12.0/neck_review.jpg。`tests/verify_webcam_distribution.py`は配布HTML一致と模擬カメラ開始/停止/拒否時案内を検査。顔検出器は模擬。Mac実カメラとOBSは未確認。
