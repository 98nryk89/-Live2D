# 無価値価値：首の修正用 作画依頼書

目的：正面を基準に左右5度かしげたとき、顎と首が自然につながり、首の太さ・顎下の影・襟との重なりが破綻しないようにする。
作り直す対象は首周りです。顔のデザイン、目・口の表情、髪、熊、衣装、装飾の描き直しは不要です。

## 差分画像は有効か

左右のかしげ差分は「その角度で首がどう見えるのが正しいか」の見本として有効です。首の輪郭と顎下の見え方を作画した差分をお願いします。
胴・肩・襟は同じ位置に固定し、顔は正面を向いたまま頭頂を左右へ倒します。画像全体を回転させた差分では首の形の資料になりません。

正面・左右の完成画像だけでは、首の肌、影、襟を個別に動かす情報が不足します。可能なら以下のレイヤー分けもお願いします。

## 推奨する納品物：正面のレイヤー付きPSD 1個 ＋ 完成見本PNG 3枚

### 1. 正面のPSD（難しければ同じキャンバスのレイヤー別透過PNG）

- 頭：顎まで。現状の顔・髪を流用し、首の肌と顎下の影を別にする。
- 首の肌：顎下の影を焼き込まない。顎に隠れる上側と襟に隠れる下側を、それぞれ20〜30px程度描き足す（1350×1165の場合）。首の左右の線を自然に描く。見えている範囲だけで切らない。
- 顎下の影：背景透過の独立レイヤー。首の肌や顎の輪郭と分離する。重ねたときの完成見本も添付する。
- 襟の奥側：首の後ろに回る部分。
- 襟の手前側：首の下部を手前から隠す部分。

胴体などの既存素材は流用します。襟の境界で首の肌をぴったり切らず、下に隠れる重なりを残してください。

### 2. 首の形の完成見本 3枚

| ファイル名 | 顔・首の姿勢 | 固定するもの |
| --- | --- | --- |
| neutral_0.png | 頭が真っ直ぐな正面 | 胴・肩・襟・熊 |
| screen_left_5.png | 見る人から見て頭頂が左へ約5度倒れる | 胴・肩・襟・熊 |
| screen_right_5.png | 見る人から見て頭頂が右へ約5度倒れる | 胴・肩・襟・熊 |

3枚とも目を開けた同じ通常表情・閉じ口にしてください。顔を左右へ向けず、正面を向いたままかしげます。
特に、顎から首への接続、首の左右のカーブ、かしげたときの太さ、顎下の影、襟との前後関係を描いてください。
最初はこの3枚で進めます。±2.5度などの追加差分を最初から作る必要はありません。

## 画像の条件

- 原本と同じ1350×1165pxの全体キャンバス。PNGは背景透過、sRGB推奨。
- レイヤー別PNGもすべて同じ大きさ・同じ座標。自動トリミング、パーツごとの拡大縮小はしない。
- 高解像度で作る場合も全素材を同じ倍率・同じ位置関係に統一し、元のキャンバスに戻せるようにする。単なる拡大は不要。
- 顔・髪・衣装の色や模様、目や口の形を変えない。
- 影と肌を分離し、顎・首・襟に隠れる部分も描く。背景の白や市松模様を画像へ焼き込まない。

## 同梱の参考画像の使い方

- original_base.png：提供された変更後ベースの原本。キャラクターの画風・色・衣装・細部の基準。元の頭には傾きがあるため、そのままを新しい0度の基準にはしない。
- upright_placement_reference.png：現在承認されている、真っ直ぐな頭の位置・大きさの参考。首は未修正の状態なので、首の形・影は作画の正解としてコピーしない。

## 依頼者がすること

1. この依頼書と上の参考2枚を、元の絵師さん、または首周りの加筆とレイヤー分けができる方へ渡す。「既存の顔・衣装は流用し、首周りを修正」と伝える。
2. 正面PSD（またはレイヤー別PNG）と、0度・画面左5度・画面右5度の完成見本PNGを受け取る。
3. ファイルを一つのZIPにまとめ、この会話へアップロードする。PSDが難しければ同じキャンバスのレイヤー別PNGでよい。

## 素材を受け取った後の実装方針

顎までの頭・首の肌・顎下の影・襟の前後を分け、首の左右輪郭と太さを完成見本3姿勢に合わせて調整する。影は顎に追従させ、首の肌の外へ出さず、手前の襟で下端を隠す。
正面と両端だけでなく±2.5度などの途中姿勢を描画し、首の太さ、顎下のつながり、影、襟の重なりを比較して動作GIFを確認する。
目・口・熊・装飾の承認済み処理は維持する。全身画像を切り替えて首を動かす方式にはしない。

これらの素材は形と隠れ領域の推測を減らすためのものです。素材を受け取っただけで自然さが保証されるものではなく、変形と重なりの設計・見た目の確認も必要です。
