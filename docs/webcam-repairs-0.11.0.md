# Webカメラ版0.11.0：V完成版を基準に元絵の首へ作り直し

依頼：生成した首肌では輪郭・陰影が失われたため、「Vセットアップ」の完成版を参照して、首元と可動域を作り直す。

## 実際に確認した完成版

98nryk89/VのMOTION-5完成版 `91f240f75a437830697126397fce60a8202b6b16` を読み取り専用で取得し、projects/owl_prince/rig_spec.json、parts_spec.json、head_model.json、tools/refine_face.py、docs/face-mouth.mdを確認。承認済みWebカメラ配布 `6a5e70a5f69bfcb85706e82e5ffa9149319b78d9` と首・頭のテンプレートが同一であることも比較した。
参照した値とファイルSHA256はreference_sources/v_completed_neck.jsonに固定し、今回の生成画像を参照値の根拠にしない。

- 左右向きAngleX：-5〜+5度。
- 上下AngleY：下10度〜上5度。
- かしげAngleZ：-5〜+5度。
- 頭と首と胴を分け、頭・目・口は同じ頭変換。首だけy方向の直線的な重みで胴へつなぐ。
- 首の深度は横方向の円柱断面。元画像の首の画素と陰影を使い、顔の後ろに重複する顎線だけ元の首の肌で補う。

Vのキャラクターの画素や座標をそのまま移植しない。Vの顔マスクの顎下端y568と首の固定側y640に対し、このキャラの顎y435・襟元y490を対応させた。縦倍率55/72により、回転支点y610→467.08、首の頭追従側y540→413.61、固定側y640→490へ写す。以前の低い支点y485を使い続けない。首の深度単位は既存の顔の奥行きに合わせて調整し、顔の形と正面の見え方を維持する。

## 今回の構成

- 首のテクスチャは変更後ベースの原本のみ。生成した首単体・新しい3姿勢・0.10.0の影素材は使用しない。輪郭線と見えている肌・陰影を残し、色を平坦化しない。
- Vと同様、首を独立した元絵パーツとして重ねる。頭の後ろに隠れる余裕を設け、首にコピーされた顎線の重複だけ、同じ原画の顎直下の肌から局所的に補う。
- 襟の線は胴・襟側に残す。首の下側の隠れ領域に襟の線をコピーして動かさない。傾けて見える襟裏の小さい範囲は、原画の裏地画素から後ろへ延長する。Vの隠れた衣装の下地と同じ目的で、AI生成した肌ではない。
- 0.10.0の独自の首曲面、追加した別の顎影、首肌の色合わせは描画経路から撤去。viewer/neck.jsも現行HTMLへ同梱しない。元絵の顔の前に新しい皮膚や影を足さない。
- 正面の頭の補正、承認済みの表情・口・熊の笑顔と4秒瞬き、装飾の重力と小さめの揺れ量は維持。頭の支点変更に合わせて、耳飾りの取付点の親変換だけ更新する。
